## How to Contribute

### Reporting Bugs

Before submitting a bug report:
1. Check if the bug has already been reported in [Issues]({{ISSUES_URL}})
2. Ensure you're using the latest version
3. Collect the following information:
   - OS and version
   - {{LANGUAGE}} version
   - Steps to reproduce
   - Expected vs actual behavior

Use the [Bug Report template]({{BUG_REPORT_TEMPLATE_URL}}).

### Suggesting Features

Feature requests are welcome! Please:
1. Check if the feature has already been requested
2. Provide a clear description of the feature
3. Explain why it would be useful

Use the [Feature Request template]({{FEATURE_REQUEST_TEMPLATE_URL}}).

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes following our coding standards
4. Add tests for your changes
5. Ensure all tests pass (`{{TEST_COMMAND}}`)
6. Commit with a clear message (see [Commit Guidelines](#commit-guidelines))
7. Push to your branch
8. Open a Pull Request

## Commit Guidelines

We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat: add new feature`
- `fix: resolve bug`
- `docs: update documentation`
- `style: formatting changes`
- `refactor: code refactoring`
- `test: add tests`
- `chore: maintenance tasks`

### Commit Message Format

```
<type>(<scope>): <subject>

<body>

<footer>
```
